Three straightforward steps

Review list revisions, without rebuilding your spreadsheet.

The proposed workflow focuses on one job: help you identify what changed before you revisit your estimate.

1

Choose two files

Select the original and revised structured equipment lists (CSV or XLSX). The planned tool would process the files without altering the originals.

2

Match by Asset ID

Choose a stable identifier such as Asset ID or Serial Number. Reordered rows would not count as changes.

3

Review an Excel report

See which assets were added, removed or changed, and which ambiguous identifiers need manual attention.

Does this page already compare files?

No. This is a concept preview with illustrative sample files and a sample report. There is no upload or processing feature yet.

Will the original equipment lists be changed?

The proposed workflow is read-only. Any final application must preserve both source files and make every ambiguity visible.

What happens with duplicate IDs?

We plan to flag duplicate and blank identifiers rather than silently guessing which records belong together.

What file types will be supported?

CSV and basic XLSX files are planned. Complex formulas, multi-table layouts, macros and scanned files would be outside the initial scope.
